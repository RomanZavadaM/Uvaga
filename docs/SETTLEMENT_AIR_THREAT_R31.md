# r31 — Інформування про повітряні загрози для обраного населеного пункту

**Статус: дизайн та критерії приймання, без live-інтеграції.** 2026-11-02.

## Мета

Користувач вручну обирає населений пункт. ТривогА повідомляє про підтверджені **повітряні загрози для його офіційно визначеної адміністративної території**: чи активна тривога, коли з'явилось повідомлення, що повідомило перевірене джерело, який тип загрози вказано, коли дані оновлено, що рекомендовано робити.

**Не створювати** розрахунків координат, швидкості, маршруту чи ETA підльоту ракет/БПЛА до заданого пункту. Для цивільної безпеки корисніше своєчасне офіційне попередження з явним часом і станом надійності. Лише офіційно оприлюднені узагальнені зони небезпеки, без перетворення на трекер цілей.

## Мінімальна картка

- **Пункт:** вибраний користувачем код населеного пункту / відповідна громада / район / область; показати межі точності.
- **Повітряна тривога:** активна / підтверджений відбій за актуального джерела / історично підтверджений відбій, але дані застаріли / невідомо.
- **Вид небезпеки:** «ударні БПЛА», «ракетна загроза» або «тип не уточнено», тільки якщо це прямо вказано в компетентному джерелі.
- **Час:** `issued_at`, `received_at`, `last_successful_sync` (розрізнити час події, час повідомлення та затримку).
- **Територія повідомлення:** область, район, громада або офіційна узагальнена зона, із зазначенням відповідності обраному пункту.
- **Джерело:** назва, посилання, роль (офіційне/допоміжне), стан перевірки.
- **Дія:** «Негайно перейдіть в укриття» за активного офіційного сигналу; не замінювати офіційні інструкції на самостійні прогнози.

## Каталог кандидатних джерел для дослідження (не підключати без дозволу)

1. Офіційні сигнали системи «Повітряна тривога»: https://www.ukrainealarm.com/ ; доступ до API та права використання перевіряти окремо.
2. Офіційна узагальнена карта: https://map.ukrainealarm.com/ — орієнтовні типи цілей і зони підвищеної небезпеки. Інформація може бути затримана й неповна; не використовувати для автоматичного ETA чи зняття тривоги. Потрібна перевірка ліцензії/наявності документованого інтерфейсу до використання даних.
3. Офіційні текстові повідомлення Повітряних Сил ЗСУ, ОВА, ДСНС; допустимий спосіб приймання та автентичність погодити окремо.
4. Агрегатори (напр. alerts.in.ua) — додаткове зіставлення; не можуть самостійно підтвердити чи скасувати офіційну тривогу.

Першоджерело → перевірка автентичності → тип/територія/час → зіставлення з обраною громадою → безпечна картка. Де даних немає, показувати «не відомо», а не виводити з чуток.

## Відсіювання шуму

- Не рахувати репости незалежними підтвердженнями; зберігати походження первинного повідомлення.
- Повідомлення без перевірених часу, джерела чи території → не впливати на офіційний стан.
- Повідомлення про іншу громаду не видавати як локальну підтверджену подію.
- Суперечність джерел показувати як невизначеність; не створювати відбій за відсутністю об'єктів на карті.
- Затримка, відмова чи stale source → позначка застарілості та останній підтверджений стан.

## Етапи

A. Офлайнові fixtures і автоматичні тести для конкретного **синтетичного** населеного пункту та його громади: активна тривога, тип невідомий, незалежні типи загроз, застарілі дані, суперечливі джерела, відбій.

B. Read-only аудит доступних API, документації, дозволів та обмежень частоти. Перевірка автентичності каналів, лагів і можливостей без створення live-підключення.

C. Після окремої згоди власника: контрольоване серверне отримання офіційних даних та незалежна оцінка надійності й затримки.

D. Після окремої згоди: користувацькі сповіщення і розповсюдження.

## Критерії

Ніколи не стверджувати «безпечно» за відсутністю позначок на карті чи даних. Ніколи не прогнозувати рух реальної військової цілі, час її прибуття або координати. Не змішувати історичний відбій з актуальним. Зберігати точний час і provenance; не називати синтетичний тест live-моніторингом.
