# SOURCE_VALIDATION — правила перевірки джерел (проект, 2026-11-01)

## Незалежні класи відомостей
1. **Офіційний статус тривоги** — авторитетне джерело з документованим дозволом і технічно перевіреним API. Його підтверджена подія опрацьовується без очікування додаткових каналів.
2. **Додаткове підтверджене повідомлення** — має вказане першоджерело, час події та межі точності, дозволені умови ретрансляції.
3. **Неперевірене** — не видавати як факт чи основу для твердження «безпечно». При потребі відхилити або позначити як непідтверджене без широкого поширення.

## Процедура допуску адаптера джерела
До підключення зафіксувати: власник та офіційність; URL документації; правова підстава повторного використання; авторизація без публікації ключів; географічна гранулярність; способи відбою та поновлення; швидкість/ліміти; частота оновлення; механізми часу і порядку подій; відомі відмови та тест fallback. Статус кожного кандидата: не перевірено / дозволено для тестів / перевірено в ізоляції / прийнято до production за рішенням власника.

## Обробка
- Порядок: отримати → визначити справжність/походження → нормалізувати → перевірити часові мітки → усунути дублікати → обчислити стан → видати відповідно до каналу.
- Повторення одним джерелом у різних каналах не є незалежним підтвердженням.
- Пріоритет: офіційний початок/відбій не відкладаємо для звірки з неофіційними повідомленнями; додаткова інформація не змінює офіційний статус.
- Кожне повідомлення містить посилання на джерело, час події, час отримання та територію лише з тією точністю, яку дає джерело.
- Несумісні чи запізнілі події не перезаписують новіший достовірний стан. Для розв'язання конфліктів потрібна окрема формальна специфікація і тестові сценарії.
- Закінчення TTL додаткового повідомлення прибирає його з актуальної стрічки, але не утворює «відбою».
- Відсутність відповіді, мережевий збій, невідомий район чи пропущене оновлення → показати застарілість/невідомий стан. Не показувати «немає небезпеки» через відсутність даних.

## Безпекові обмеження
Не будувати публічне оперативне стеження за військовими об'єктами, точними траєкторіями, координатами чи ймовірними цілями. Не підміняти офіційне оповіщення. До дозволу власника — тільки документація й синтетичні тести.
