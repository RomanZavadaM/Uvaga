# PROJECT_RULES — ТривогА

## Рішення власника 2026-11-01
Публічний GitHub `RomanZavadaM/Uvaga`; продукт для населення України. Офіційні тривоги плюс додаткова підтверджена інформація. Канали: desktop, mobile, web; Telegram — пізніше, через інтеграційний вихід. Rust + Tauri 2 — погоджений попередній технологічний напрям. Власницька ліцензія за моделлю Taxo. Windows 7 виключено.

## Якість і безпека
Офіційні сигнали не замінювати припущеннями; відбій — лише підтверджений, ніколи за TTL. Втрата зв'язку означає «стан невідомий/інформація застаріла», не «безпечно». Додаткові джерела не скасовують офіційні. Не створювати живі трекери військових цілей, не публікувати неперевірені оперативні відомості.

Дозволено розробку, тести, CI, документацію та роботу з репозиторієм. Реальні production-розгортання, публічні сповіщення, отримання/використання live API credentials та прийняття зовнішніх API-оферт потребують окремого рішення власника.

## Режим виконавців
- За замовчуванням у проєкті працює один активний виконавець.
- Паралельну роботу запускає тільки власник.
- Власник не запускає двох виконавців одночасно на одну гілку/той самий матеріал.
- Перед записом завжди звіряти live HEAD, PR і незавершену роботу, щоб не дублювати або перезаписувати попередню сесію.
- Якщо власник колись дозволить паралельність, робота розділяється по окремих гілках/ділянках і потім звіряється перед інтеграцією.

Документи і код — GitHub; Google Drive — одностороннє дзеркало/checkpoint/backup, не альтернативне джерело істини.

## Процес
Малий етап → критерії приймання до реалізації → окрема гілка/PR → тести/CI/змістова перевірка → поетапна інтеграція → запис у WORKLOG/HANDOFF. Не повідомляти про тест, sync, backup чи готовність без фактичного доказу. Stacked PR інтегрувати base-first з fresh CI після retarget.

## Методологія
Пробне застосування dev-strategy v2 RC (central main 2026-11-01). Правила цього проєкту самодостатні для звичайних сесій. Формальне приймання C01–C14 — лише після фактичних доказів і рішення власника.
