# PROJECT_RULES — ТривогА
## Рішення власника 2026-11-01
Публічний GitHub RomanZavadaM/Uvaga; продукт для населення України. Офіційні тривоги плюс додаткова підтверджена інформація. Канали: desktop, mobile, web; Telegram — пізніше, через інтеграційний вихід. Rust + Tauri 2 — попередній, не прийнятий як реалізований стек. Власницька ліцензія за моделлю Taxo. Windows 7 виключено.
## Якість і безпека
Офіційні сигнали не замінювати припущеннями; відбій — лише підтверджений, ніколи за TTL. Втрата зв'язку означає «стан невідомий/інформація застаріла», не «безпечно». Додаткові джерела не скасовують офіційні. Не створювати живі трекери військових цілей, не публікувати неперевірені оперативні відомості.
Будь-які реальні повідомлення, зовнішнє розгортання, API-ключі і publication потребують окремого дозволу; зараз дозволено лише docs-only.
## Спільна робота
Одна активна операція над однією гілкою/матеріалом; окремі гілки для різних ШІ/людей. Перед записом перевірити HEAD, PR та чужу незавершену роботу. Унікальну неопубліковану роботу зберігати відновлювано. Не змінювати чужу гілку одночасно. Документи і код — GitHub; Drive — лише одностороннє дзеркало.
## Процес
Малий етап → заздалегідь задані критерії → гілка/PR → незалежна перевірка → рішення власника щодо merge/release. Запис у WORKLOG: дія, SHA/доказ, обмеження, наступний крок. Релізи не переписувати. Не повідомляти про тести чи синхронізацію без факту.
## Методологія
Пробне застосування dev-strategy v2 RC (центральний main на 2026-11-01); формальне приймання C01–C14 — після перевірки власником, не автоматично. Правила цього документа самодостатні для робочих сесій.
