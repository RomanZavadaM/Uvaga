# SOURCES — кандидати до перевірки
- Офіційний API «Повітряна тривога»: https://api.ukrainealarm.com/ (потрібні підтверджені умови/доступ).
- alerts.in.ua API: https://devs.alerts.in.ua/ (умови, повнота, ліміти, ліцензія — неперевірені).
- Додаткові агрегатори можна оцінювати лише після джерелознавчого аудиту та перевірки дозволу на повторну публікацію.
Наявність документації API НЕ підтверджує доступ, якість, поточну працездатність, право ретрансляції чи малу затримку. Немає підключених live API.
Пріоритет офіційного статусу, журнал походження, часові мітки, стани stale/unknown. Не публікувати точні оперативні траєкторії/координати цілей.
